プライバシーポリシー

制定日: 2026年10月20日

yt-shorts-factory（以下「本ツール」）は、YouTube チャンネル「まったり解説チャンネル」の運営者本人だけが使う個人用のツールです。

1. 取得する情報

本ツールは、運営者本人が Google アカウントで許可した範囲で、YouTube Data API と YouTube Analytics API を通じて次の情報を扱います。

  • 運営者のチャンネルへの動画のアップロード、タイトル・説明文などの設定
  • 運営者のチャンネルの動画の再生数などの集計データ

運営者以外の方の個人情報は取得しません。

2. 利用目的

運営者が自分のチャンネルに動画を投稿し、動画の見られ方を確認するためだけに使います。

3. 保存と第三者への提供

認証情報と取得したデータは運営者のパソコンにだけ保存します。第三者に提供・販売することはありません。

4. 許可の取り消し

Google アカウントの「サードパーティのアプリとサービス」（https://myaccount.google.com/connections）から、いつでも本ツールへの許可を取り消せます。

5. Google API サービスの利用

本ツールによる Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。YouTube の利用には YouTube 利用規約（https://www.youtube.com/t/terms）と Google プライバシーポリシー（https://policies.google.com/privacy）が適用されます。

6. お問い合わせ

上記チャンネルを通じてご連絡ください。

Privacy Policy (English)

Effective date: October 20, 2026

yt-shorts-factory ("the Tool") is a personal tool used only by the owner of the YouTube channel "まったり解説チャンネル".

  • Data accessed: with the owner's own authorization, the Tool uses the YouTube Data API and YouTube Analytics API to upload videos to the owner's channel, edit their metadata, and read aggregated analytics of the owner's channel. No data of other users is collected.
  • Use: only for the owner to publish videos and review their performance.
  • Storage and sharing: credentials and retrieved data are stored only on the owner's computer and are never shared with or sold to third parties.
  • Revoking access: access can be revoked at any time at https://myaccount.google.com/connections.
  • The Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube is subject to the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).
  • Contact: via the YouTube channel above.
